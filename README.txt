RAIZAH WEBSITE STARTER
======================

Files:
- index.html: responsive starter storefront and demo admin panel.

How to preview:
1. Open index.html in a browser.
2. Browse products and try adding to bag / submitting an order.
3. Click Admin. Demo passcode: ChangeMe123!
4. Add or edit products, update stock, view order requests, set WhatsApp number and Facebook Page URL.
5. Export Data downloads a JSON backup.

IMPORTANT LIMITATIONS:
- This is a starter demo, not yet a live public website.
- Product, stock, and order data are saved only in the current browser/device using localStorage.
- The demo admin passcode is visible in the HTML and is NOT secure. Do not use this version for real customer data or publish it as a production store.
- Product photos currently use sample remote image URLs. Replace them with your actual RAIZAH product photos.
- Before launch, connect hosting, a domain if desired, a secure server-side admin login, a cloud database, image uploads, and real order notifications.
- WhatsApp number and Facebook Page URL can be configured from Admin > Contact Settings in this demo.
